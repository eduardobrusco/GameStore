# GameStore — Sistema de Gestão de Loja de Games

Projeto acadêmico em C# com Programação Orientada a Objetos.

## Como executar
1. Abra `GameStore.csproj` no Visual Studio 2022 ou superior.
2. Execute com `Ctrl + F5`.
3. Use o menu do console.
4. Os dados são salvos na pasta `Dados` em arquivos JSON.

## Conceitos de POO demonstrados
- Classes e objetos
- Propriedades
- Métodos
- Construtores
- Encapsulamento
- `this`
- `static`
- Herança
- Polimorfismo com `virtual`/`override`
- Interface
- Exceções
- Serialização JSON

## Funcionalidades extras
- Controle de estoque mínimo
- Relatório de vendas
- Busca de clientes e produtos
- Persistência em JSON
